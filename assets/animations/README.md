# Lottie Animations Directory

## Premium Crown Animation

Place your premium crown Lottie animation here as `premium_crown.json`

### Recommended Lottie Animations for Premium:

You can find great free Lottie animations on these platforms:

1. **LottieFiles** (https://lottiefiles.com)
   - Search: "crown", "premium", "gold crown", "vip"
   - Popular choices:
     - Gold Crown animation with sparkles
     - Premium badge with shine effect
     - VIP crown with glow
     - Royal crown with particles

2. **Recommended Specific Animations:**
   - **Gold Crown**: https://lottiefiles.com/animations/crown

   - **VIP Crown**: https://lottiefiles.com/animations/vip
   - **Sparkle Crown**: https://lottiefiles.com/animations/sparkle

### Best Practices:

1. **File Size**: Keep animations under 50KB for optimal performance
2. **Dimensions**: Animations work best at 56x56px (the container size)
3. **Loop**: Enable looping for continuous animation
4. **Colors**: Gold/Yellow tones (#FFD700, #FFA500) match the gradient background
5. **Transparency**: Use animations with transparent backgrounds

### How to Add:

1. Download your chosen Lottie JSON file from LottieFiles
2. Rename it to `premium_crown.json`
3. Place it in this directory (`assets/animations/`)
4. The app will automatically use it!

### Fallback:

If the Lottie file is not found or fails to load, the app will automatically fallback to a Material Icons premium icon.
