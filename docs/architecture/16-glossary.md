# 16. Glossary

> Owner: Mobile Engineering · Last reviewed: 2026-09-28 · Applies to version: Android `2.8.14+73`

| Term | Meaning |
|---|---|
| Salon / Store | A service business listed in GloUp. API and client use both terms. |
| Partner | Salon-side business user/application, outside this client. |
| Service | A bookable treatment or offering provided by a salon. |
| Slot | A date/time availability returned for a salon and selected services. |
| Appointment | A customer booking, including status and selected services. |
| Guest | A person for whom the signed-in customer can arrange a booking. |
| Gloup Cash / wallet amount | Customer balance applied during checkout where supported. |
| Platform fee | A booking charge included in the client bill breakdown; the value source must align with backend policy. |
| Payable price | Current price charged for one service, commonly represented as `price`. |
| Original price / MRP | List price used for comparison when a discount exists. |
| Coupon | Promotional discount validated/applied during booking. |
| `userauth` | HTTP request header used by the app to send its access token. |
| FCM | Firebase Cloud Messaging, used for remote push notification delivery. |
| Shorebird patch | Over-the-air Dart code update associated with a Shorebird release; native changes require a store build. |
